# API Blueprint

Future API Groups to be implemented (RESTful JSON APIs):

- `/api/auth`: Login, SSO integration, token refresh.
- `/api/users`: CRUD for user management (Admin only).
- `/api/profile`: Fetch/update current user details.
- `/api/competencies`: Fetch frameworks, user's current competencies, history.
- `/api/assessments`: Fetch quizzes, submit attempts, calculate scores.
- `/api/skill-gaps`: Fetch computed gaps for the current user.
- `/api/learning`: Fetch resources, paths, and update progress.
- `/api/recommendations`: AI-generated personalized suggestions.
- `/api/ai`: Trigger and poll async AI generation jobs (Admin only).
- `/api/questions`: Review, edit, approve AI-generated questions (Admin only).
- `/api/admin`: Workforce statistics and aggregations.
- `/api/analytics`: Data for charting and dashboards.
- `/api/integrations`: Webhooks or endpoints for iGOT/NSSTA.
- `/api/notifications`: Fetch and mark alerts as read.

*(Note: These are planned endpoints and are not yet implemented in Phase 2.)*
