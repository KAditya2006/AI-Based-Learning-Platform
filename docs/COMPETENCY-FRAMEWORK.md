# Competency Framework

## Domains
Based on the MoSPI problem statement, the competencies are categorized into:
1. **Statistical Competencies** (e.g., Data Collection, Sampling, Analysis)
2. **Technical Competencies** (e.g., R, Python, Data Visualization, DB Management)
3. **Digital Governance Competencies** (e.g., Data Privacy, e-Governance standards)
4. **Behavioural/Managerial Competencies** (e.g., Project Management, Leadership)

## Competency Levels
Each competency is measured on a 5-point scale:
1. **Beginner:** Basic awareness.
2. **Basic:** Can perform tasks with guidance.
3. **Intermediate:** Can perform tasks independently.
4. **Advanced:** Can guide others and handle complex scenarios.
5. **Expert:** Subject matter expert, shapes strategy.

## Key Concepts
- **Current Competency:** The official's currently proven level.
- **Required Competency:** The level required by their specific Role/Designation.
- **Skill Gap:** The delta between Required and Current.
- **Competency Evidence:** The assessment result, certificate, or manager approval that validated the current level.
- **Competency History:** A chronological audit log of how and when a competency level changed.
