# UI/UX Design Strategy

## Design Principles
- **Government-Grade & Professional:** The platform must exude trust and credibility, appropriate for MoSPI.
- **Calm & Information-Focused:** Prioritize information hierarchy over decoration. The data must speak for itself.
- **Accessible & Data-Driven:** Compliance with accessibility standards and focus on clear data visualization.
- **Human-Designed:** Avoid generic AI-generated SaaS aesthetics (e.g., excessive gradients, neon colors, floating elements).

## UI Patterns per Intent
- **Workforce / Directory:** Use dense, scannable Data Tables.
- **Analytics:** Use clear Charts (Bar, Line, Radar for competencies).
- **Competency:** Progress indicators and visual comparisons (Target vs Current).
- **Learning:** Content-first layout, minimal distractions, legible typography (Inter/Roboto).
- **Assessment:** Focused, distraction-free interface, clear timer/progress.
- **Onboarding:** Structured step-by-step Wizard.
- **AI Assistant:** Contextual side-panel or inline interaction (no arbitrary floating chat bubbles covering content).

## Responsive Design
- **Desktop:** Full data tables, multi-column analytics, expansive navigation.
- **Tablet:** Adaptive grids, touch-friendly targets, collapsible sidebars.
- **Mobile:** Single-column content, bottom tab navigation, simplified data views (cards instead of wide tables).

## Design Tool Workflow
Figma is the source of truth for the visual system.
Workflow:
1. Real product research & requirements definition.
2. Information architecture & wireframing.
3. Figma UI design.
4. Design review & approval.
5. Frontend implementation (AI tools strictly follow the Figma designs).
